Differences:
- Production parses only files that are part of the module tree (no dot-folders, node_modules, or symbolic links).
  That is 166 fewer blobs.
- The payload carries imported names (6.2 MB of the 15 MB), file roles, and the unresolved list. The prototype's
  file had none of them.
- The resolution rate is resolved import references / (resolved references + unresolved entries). Unresolved
  entries are deduplicated per (file, line, specifier), so the two counts differ only when one line repeats a
  specifier.
